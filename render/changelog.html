ECL-1 change log

For each version of ECL-1, and each candidate that preceded Version 1.0, that the requirement ledger records, this log gives the requirements that it introduced, changed and retired, by identifier, with the document and the section where each requirement stands. A requirement is changed in a version when its text differs from its text in the version before; a text that changes within the version that introduced it is new there, not changed. The ledger begins with the requirements of the frozen RC-3 candidate, which it records as introduced in 1.0-rc.3. The text of each requirement is in the document named and in registries/requirements-compiled.json. The wire values and registry entries that changed between versions are listed in the release notes of each version (RELEASE-NOTES-1.0.md for Version 1.0). Like the rest of the text of ECL-1, this log is licensed under CC BY 4.0, as LICENSING.md states.

The historical version sections are generated from registries/requirement-ledger.json (version 1.0). The correction section is generated from release/CORRECTIONS-1.0.1.json by scripts/generate_correction_changelog.py, using the preserved original release archive as its historical input.

Correction release 1.0.1

This release corrects the Version 1.0 source and the accompanying Version 1 reference edition (erratum ERR-1.0-001). It retains all 628 requirement identifiers; 53 requirement texts differ from the original publication. The exact before/after texts are in CORRECTIONS-1.0.1.json. The release notes describe the verifier, model, corpus, explanatory and governance corrections. The earlier version ledger below remains the historical record of the original release.
